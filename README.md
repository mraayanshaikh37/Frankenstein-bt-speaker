# 🔊⚡ Frankenstein BT Speaker


A Bluetooth speaker built entirely from salvaged electronic components.

This project has gone through multiple revisions over the years, evolving from a noisy AUX-powered speaker into a Bluetooth speaker using recycled modules, amplifier ICs, and handmade circuitry. Every version taught something new through debugging, failures, and rebuilding.

---

## 📖 About

The enclosure is made from a recycled **1 kg cottonseed oil carton**, while almost every electronic component has been recovered from discarded devices.

Instead of buying new parts, the goal was to create a functional Bluetooth speaker from electronic waste and continuously improve it through experimentation.

Current version: **v3 (Under Repair / Debugging)**

---

## 📦 Specifications

| Feature | Details |
|---------|---------|
| Enclosure | Recycled Cottonseed Oil Carton |
| Drivers | 3 Oval Full-range Speakers |
| Subwoofer | 1 Round Woofer |
| Amplifier | PAM8403 |
| Bluetooth | Salvaged Bluetooth Audio Module |
| Power Supply | 12V Adapter + 7805 Voltage Regulator |
| Status | Debugging |

---

## 🔊 Speaker Configuration

- 3 × Oval full-range speakers (salvaged from an old TV)
- 1 × Round subwoofer driver (from TV sub enclosure)

# 📈 Version History

| Version | Changes |
|----------|---------|
| v0.1 | AUX powered speaker (worked with heavy noise) |
| v0.5 | Added salvaged Bluetooth receiver with IC6283 amplifier |
| v1 | Used dedicated amplifier IC with Bluetooth module |
| v2 | Switched to premade Bluetooth amplifier board |
| v2.5 | Upgraded amplifier to PAM8403 |
| v3 | Added regulated 5V supply (7805). Power stage short damaged Bluetooth module and amplifier. |

# 🎯 Why This Project Exists

Building a Bluetooth speaker from salvaged parts has been a childhood dream.

This project isn't about making the perfect speaker.

It's about proving that discarded electronics can become something useful again through curiosity, patience, and continuous improvement.

Every failed version became the foundation for the next one.

> **"One small step toward a dream. One giant leap toward a comeback."**
